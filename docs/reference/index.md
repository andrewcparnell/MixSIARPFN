# Package index

## Load data (as MixSIAR)

- [`load_mix_data()`](load_mix_data.md) : Load mixture (consumer) data
- [`load_source_data()`](load_source_data.md) : Load source data
- [`load_discr_data()`](load_discr_data.md) : Load discrimination (TDF)
  data
- [`plot_data()`](plot_data.md) : Isospace plot of the data, as
  MixSIAR's plot_data()

## Fit and summarise

- [`run_pfn()`](run_pfn.md) : Fit a MixSIAR model with the prior-data
  fitted network
- [`output_pfn()`](output_pfn.md) : Summaries and plots of a fit, like
  MixSIAR's output_JAGS()
- [`summary_table()`](summary_table.md) : The summary statistics table
  of a fit
- [`posterior_draws()`](posterior_draws.md) : Draws from the marginal
  posteriors
- [`pfn_networks()`](pfn_networks.md) : Where the networks are cached,
  and whether they are there

## Compare with MixSIAR

- [`mixsiar_reference()`](mixsiar_reference.md) : MixSIAR's own fits of
  the example data
- [`mixsiar_draws()`](mixsiar_draws.md) : Diet proportion draws from a
  MixSIAR fit
- [`compare_mixsiar()`](compare_mixsiar.md) : Compare a fit with
  MixSIAR's posterior
- [`plot_compare()`](plot_compare.md) : Plot a fit against MixSIAR's
  posterior
- [`plot_compare_covariate()`](plot_compare_covariate.md) : Compare
  diets along a continuous effect with MixSIAR's
